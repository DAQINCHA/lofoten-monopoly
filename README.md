# 罗弗敦大富翁 · Lofoten Monopoly

极光下的渔村地产战。经典大富翁规则 + 罗弗敦群岛主题，浏览器打开就能玩，支持局域网联机（2–6 人）。

零第三方依赖，只需要 Node.js 18+。

## 启动

```bash
npm start          # 或 node server.js
```

启动后终端会打印：

```
本机访问:   http://localhost:5200
局域网:     http://192.168.x.x:5200
```

同一 Wi-Fi 下的手机、平板、电脑打开局域网地址即可。一个人点「创建房间」拿到 4 位房间码，其他人输入房间码加入；也可以用「邀请链接」直接进。

想换端口：`PORT=8080 node server.js`

## 一个人玩 / 机器人

- 大厅直接点 **「单人对战 3 个机器人」**，一步开局，不用等人。
- 或者在等待房间里点 **「＋ 机器人」**、**「补到 4 人」**，房主想加几个加几个（最多 6 人），点机器人右上角的 ✕ 可以移除。
- 机器人会自己买地、建房、赎回抵押、坐牢时选保释或掷对子，也会**评估你发来的交易报价**——划算就接受，会被你凑成套装就狮子大开口。

机器人决策在 `lib/bot.js`，服务端定时器驱动（`server.js` 的 `scheduleBots`）：轮到机器人时，服务器每 0.3–0.8 秒走一步并广播，人类玩家不需要保持在线之外的任何操作。

## 开局前

- **随机起名**：大厅名字框右边的 🎲 随机按钮，会从 133 个罗弗敦职业名（渔夫、极光向导、灯塔看守、鱼汤摊主……）里抽一个；带上房间码进入时会避开房里已有的名字，服务端入座时还会给重名补后缀。
- **棋子**：24 个海洋与海岛主题的 emoji 棋子池，同一房间内不重复，每局都不一样。
- **掷骰定序**：等待房里每人可以掷一次双骰，点数大的先出手；同点比单颗最大，再同则先入座者优先。没掷的人开局时自动补掷，开局日志会打印完整出手顺序。

## 玩法

- **目标**：让其他玩家全部破产，成为最后的岛主。
- **金额**：单位 kr（挪威克朗）。起始 kr 150,000，经过起点领 kr 20,000；地价 kr 6,000–40,000，建房 kr 5,000–20,000 一栋。
- **查看资产**：点左侧任意玩家卡片，可以看到他的现金、总净值、全部地产（房屋 / 酒店 / 抵押状态）和手上留着的命运卡。
- **局内聊天**：左下角「岛民频道」，全房间实时可见，回车发送；消息保留最近 60 条，服务端限流防刷屏。
- **银行库存**：房屋与酒店的剩余数量显示在棋盘中央右上角，与左上角的「罗弗敦大富翁」水印左右对称。
- **命运卡**：极光卡与命运卡里有可保留的卡——免费渡轮票（出狱用）和渔市议价券 / 老船长的欠条（付租自动减半），用掉才消失。
- **回合**：掷两颗骰子前进。掷出对子可再掷一次；连续三次对子直接进监狱。
- **买地**：停在无主地块可按标价买下；放弃则留在银行。
- **收租**：停在别人地产要付租。集齐同色地块，空地租金翻倍。
- **建造**：集齐同色地块后可以建房，必须平均建造；4 栋房屋升级为酒店，租金大幅提升。
- **抵押**：抵押获得半价现金，赎回多付 10%，抵押期间不收租。
- **监狱**：付 kr 5,000 保释、用免费渡轮票，或掷对子脱身（最多 3 次）。
- **破产**：现金不足会自动变卖房屋、抵押地产；仍然不够就出局，资产归债主。
- **交易**：自己的回合内可以发起「地产 + 现金」交换，对方接受后立即生效。

## 声音

- **BGM**：北欧海岛 lo-fi——手风琴铺底、木琴主旋律、木质打击乐，底下垫一层缓慢起伏的海浪噪声。96 BPM，8 小节（约 20 秒）无缝循环。
- **音效**：掷骰、骰子落定、走子、买地、收租、建房 / 升酒店、抽卡、入狱 / 出狱、破产、胜利……每个事件都有对应的声音，和中央大屏的播报同步响起。
- **开关**：右上角 🔊 按钮里可以分别调「音乐 / 音效」音量或一键静音；按 **M** 键也能快速静音。设置存在本地，下次打开还在。默认音乐 30% 音量。
- 所有声音都是**浏览器实时合成**的（Web Audio），项目里没有任何音频文件，也不依赖第三方库。

### 对局长度

创建房间后可选 40 / 80 / 120 回合，或无上限（打到只剩一人）。默认 80 回合；到达上限时按「现金 + 地产 + 建筑」的总净值排名定胜负。回合数会显示在右侧回合栏。

> 没有回合上限时，如果大家都集不齐色组、只靠过路费，游戏可能拖得很长——成套建房才是让对手破产的正道，差一块时记得用交易去换。

## 技术实现

- 服务端：`server.js`（原生 HTTP）+ `lib/game.js`（房间与规则引擎）+ `lib/board.js`（棋盘卡牌数据）+ `lib/bot.js`（机器人决策）
- 实时同步：SSE（`/api/stream`）推送全量状态，操作走 `POST /api/action`
- 前端：`public/` 下原生 ES Module + CSS，无构建步骤
- 状态全在服务端内存中，刷新页面可用本地保存的身份令牌自动重连；服务重启则房间清空

## 云端版（Cloudflare Workers）

同一套游戏还有一个云端部署包，放在 `edge-services/lofoten-monopoly-worker/`，
一个 Worker 同时提供网页和联机服务，接口与本版**完全一致**（前端也共用 `public/` 这一份）。

源码只有这一处：`lib/` 和 `public/` 是**唯一真身**，云端包里的对应文件是构建时复制过去的。
所以——

> **改了 `lib/` 或 `public/`（棋盘、规则、机器人、页面），要去云端包目录跑一次 `npm run build:edge`，
> 把生成的文件一起提交。**

只改了 `server.js` 的端口/启动横幅、启动脚本之类的东西，则不用管云端包。
完整清单（哪些要重建、哪些不用、哪些要手动两边同步）见该目录的 `README.md` 与 `AGENTS.md`。
